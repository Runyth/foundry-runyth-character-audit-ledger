# Contributing

- Use `master` as the default branch.
- Keep capture system-agnostic. Do not add a language selector or a hard dependency on Tidy 5e Sheets.
- Program source is `AGPL-3.0-or-later`. This module ships no gameplay content.
- Run `npm ci --ignore-scripts` and `npm run check` before submitting changes.
- Do not commit workstation paths, access tokens, private keys, player names, or world exports.
